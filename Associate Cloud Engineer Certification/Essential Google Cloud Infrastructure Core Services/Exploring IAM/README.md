## Estimated Time: 5 minutes

## How to Run

1. Create the script file in Cloud Shell:
   ```bash
   nano script.sh
   # (Paste the script code, then press Ctrl+S to save, and Ctrl+X to exit)
   ```

2. Make it executable and run it:
   ```bash
   chmod +x script.sh
   ./script.sh
   ```

3. *(Optional)* If your lab assigned a different region, zone, or User 2:
   ```bash
   REGION="your-region" ZONE="your-zone" USER_2="student-XX-XXXX@qwiklabs.net" ./script.sh
   ```
