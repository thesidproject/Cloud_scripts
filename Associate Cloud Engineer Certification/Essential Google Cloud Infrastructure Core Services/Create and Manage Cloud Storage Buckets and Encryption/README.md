# Create and Manage Cloud Storage Buckets and Encryption

## Estimated Time: 5 minutes

## How to Run

1. Create the script file in Cloud Shell:
   ```bash
   nano script.sh
   ```
###  (Paste the script code from VS Code, then press Ctrl+S to save, and Ctrl+X to exit)

2. Make it executable and run it:
   ```bash
   chmod +x script.sh
   ./script.sh
   ```

3. *(Optional)* If your lab assigned a different region or bucket name:
   ```bash
   REGION="your-region" BUCKET_NAME_1="your-bucket-name" ./script.sh
   ```
