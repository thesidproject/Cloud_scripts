# Build Infrastructure with Terraform on Google Cloud Challenge Lab

## Estimated Time: 12 minutes

## How to Run

1. Create the script file in Cloud Shell:
   ```bash
   nano script.sh
   ```
###  (Paste the script code from VS Code, then press Ctrl+S to save, and Ctrl+X to exit)

2. Make it executable and run it:
   ```bash
   chmod +x script.sh
   ./script.sh
   ```

3. *(Optional)* Override parameters inline if assigned different values:
   ```bash
   BUCKET_NAME="tf-bucket-321642" INSTANCE_3_NAME="tf-instance-717102" VPC_NAME="tf-vpc-928990" ./script.sh
   ```
