# Creating Resource Dependencies with Terraform

## Estimated Time: 2:30 minutes

## How to Run

1. Create the script file in Cloud Shell:
   ```bash
   nano script.sh
   ```
### (Paste the script code, then press Ctrl+S to save, and Ctrl+X to exit)

2. Make it executable and run it:
   ```bash
   chmod +x script.sh
   ./script.sh
   ```

3. *(Optional)* Override parameters inline if assigned different values:
   ```bash
   REGION="us-east1" ZONE="us-east1-c" INSTANCE_1_NAME="myinstance" INSTANCE_2_NAME="terraform-instance-2" ./script.sh
   ```
