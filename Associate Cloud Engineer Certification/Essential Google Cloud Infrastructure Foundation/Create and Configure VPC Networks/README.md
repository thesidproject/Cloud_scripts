# Create and Configure VPC Networks

## Estimated Time: 10 minutes

> [!WARNING]
> **Status: Not tested**

## How to Run

1. Create the script file in Cloud Shell:
   ```bash
   nano script.sh
   ```
###  (Paste the script code, then press Ctrl+S to save, and Ctrl+X to exit)

2. Make it executable and run it:
   ```bash
   chmod +x script.sh
   ./script.sh
   ```

3. *(Optional)* Override parameters inline if assigned different values:
   ```bash
   REGION_1="us-east1" ZONE_1="us-east1-c" REGION_2="europe-west4" ZONE_2="europe-west4-c" ./script.sh
   ```
