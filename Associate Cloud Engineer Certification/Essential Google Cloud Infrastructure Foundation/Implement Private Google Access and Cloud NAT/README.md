# Implement Private Google Access and Cloud NAT

## Estimated Time: 9 minutes

## How to Run

1. Create the script file in Cloud Shell:
   ```bash
   nano script.sh
   ```
###  (Paste the script code from VS Code, then press Ctrl+S to save, and Ctrl+X to exit)

2. Make it executable and run it:
   ```bash
   chmod +x script.sh
   ./script.sh
   ```

3. *(Optional)* If your lab assigned a different region or zone:
   ```bash
   REGION="your-region" ZONE="your-zone" ./script.sh
   ```
