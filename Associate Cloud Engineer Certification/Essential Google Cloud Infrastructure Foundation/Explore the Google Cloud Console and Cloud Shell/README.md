# Explore the Google Cloud Console and Cloud Shell

## Estimated Time: 3 minutes

> **Note for Task 1:** It is best to create the first bucket manually in the Google Cloud Console (**Cloud Storage > Buckets > Create**, enter a unique name and keep all defaults). The script will automatically detect your bucket and complete all remaining tasks.

## How to Run

1. Create the script file in Cloud Shell:
   ```bash
   nano script.sh
   # (Paste the script code, then press Ctrl+S to save, and Ctrl+X to exit)
   ```

2. Make it executable and run it:
   ```bash
   chmod +x script.sh
   ./script.sh
   ```

3. *(Optional)* If your lab assigned a specific region:
   ```bash
   REGION="your-region" ./script.sh
   ```
