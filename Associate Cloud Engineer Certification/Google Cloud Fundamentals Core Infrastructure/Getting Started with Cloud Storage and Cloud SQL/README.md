## Estimated Time:
~4-6 minutes (Cloud SQL provisioning takes ~3-5 minutes)

## How to Run

1. Create the script file in Cloud Shell:
   ```bash
   nano script.sh
   # (Paste the script code, then press Ctrl+S to save, and Ctrl+X to exit)
   ```

2. Make it executable and run it:
   ```bash
   chmod +x script.sh
   ./script.sh
   ```

3. *(Optional)* If your lab assigned a specific region or zone:
   ```bash
   REGION="your-region" ZONE="your-zone" ./script.sh
   ```
