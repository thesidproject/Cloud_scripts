# Develop your Google Cloud Network Challenge Lab

## Estimated Time: 6 minutes

## How to Run

1. Log in to Google Cloud Console using the assigned **Username 1** credentials.

2. Create the script file in Cloud Shell:
   ```bash
   nano script.sh
   ```
###  (Paste the script code, then press Ctrl+S to save, and Ctrl+X to exit)

3. Make it executable and run it:
   ```bash
   chmod +x script.sh
   ./script.sh
   ```

4. *(Optional)* Override region, zone, or User 2 inline if assigned different parameters:
   ```bash
   REGION="us-east1" ZONE="us-east1-c" USER_2="student-04-fbecdf0f14bd@qwiklabs.net" ./script.sh
   ```
