# Deploying GKE Autopilot Clusters

## Estimated Time: 9 minutes

## How to Run

1. Create the script file in Cloud Shell:
   ```bash
   nano script.sh
   ```
###  (Paste the script code from VS Code, then press Ctrl+S to save, and Ctrl+X to exit)

2. Make it executable and run it:
   ```bash
   chmod +x script.sh
   ./script.sh
   ```

3. *(Optional)* Override region inline if assigned a different location:
   ```bash
   REGION="us-east4" ./script.sh
   ```
